# 🚀 Como Publicar o Site - GUIA RÁPIDO

## ✅ Opção 1: GitHub Pages (3 minutos)

### Passo 1: Fazer Merge do Branch
1. Acesse: https://github.com/vitrine-show/receita-conchiglione
2. Clique em "Pull requests"
3. Crie um PR do branch `claude/create-recipe-website-01SVB9Z8C2C9AKj456UBGd17` para `main`
4. Faça o merge

### Passo 2: Ativar GitHub Pages
1. Vá em **Settings** (Configurações) do repositório
2. No menu lateral, clique em **Pages**
3. Em **Source**, selecione:
   - Branch: `main`
   - Folder: `/ (root)`
4. Clique em **Save**

### Passo 3: Aguardar Deploy
- Aguarde 1-2 minutos
- Seu site estará em: **https://vitrine-show.github.io/receita-conchiglione/**

---

## ⚡ Opção 2: Netlify (2 minutos - MAIS RÁPIDO)

1. Acesse: https://app.netlify.com/drop
2. Arraste a pasta do projeto
3. **PRONTO!** Link instantâneo: `https://nome-aleatorio.netlify.app`

---

## 🎯 Opção 3: Vercel (2 minutos)

1. Acesse: https://vercel.com
2. Clique em "New Project"
3. Importe: `vitrine-show/receita-conchiglione`
4. Clique em "Deploy"
5. Link: `https://receita-conchiglione.vercel.app`
